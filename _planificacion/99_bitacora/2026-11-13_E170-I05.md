## Nueva línea base del `dist/` (para E170-I02, I03 e I04)
- **Archivos:** 207 · **`.html`:** 30 · **sha256 (16 primeros hex):** `6d6e25a0e8865015`
- **Sistema:** Windows 10, Node v24.16.0, pnpm 12.15.0, PowerShell 7, tras `pnpm build` (se reconstruyó dos veces y dio la misma huella).
- **Método:** ruta relativa a `dist/` con `/`, orden ordinal; líneas `ruta<TAB>sha256 en minúsculas`; unidas con `\n`; sha256 UTF-8 del texto; 16 primeros hex.

```powershell
# PowerShell 7, desde la raíz, después de `pnpm build`
$root = (Resolve-Path dist).Path
[string[]]$rel = Get-ChildItem dist -Recurse -File | ForEach-Object { $_.FullName.Substring($root.Length + 1).Replace('\', '/') }
[Array]::Sort($rel, [StringComparer]::Ordinal)
$lines = foreach ($f in $rel) { "$f`t" + (Get-FileHash -Algorithm SHA256 -LiteralPath (Join-Path $root $f)).Hash.ToLower() }
$hash = [Convert]::ToHexString([Security.Cryptography.SHA256]::HashData([Text.Encoding]::UTF8.GetBytes($lines -join "`n"))).ToLower().Substring(0, 16)
"{0} archivos, {1} .html, sha256 {2}" -f $rel.Count, ($rel | Where-Object { $_ -like '*.html' }).Count, $hash
```

Reproducibilidad: sobre `69b391b` el método dio `628994afbec63292` en Windows (mi build de esta sesión y el de Felipe) y en Linux (build de Felipe). La huella histórica `bcae4302f5d8f3ae` no se reproduce y se reemplaza (AT-116).
