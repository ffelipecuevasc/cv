## Procedimiento para Felipe · ADR-124 (apagar `preview_urls`)
Desde que se apague, `ajustes-visuales` deja de tener URL de preview. Hazlo cuando ya no necesites la preview.

1. **Rama corta desde `main`:**
   ```
   git switch main
   git pull
   git switch -c cierre-e200-preview-urls
   ```
2. **`wrangler.jsonc`:** cambia las líneas 5 a 7 del comentario y la clave `preview_urls`. Debe quedar así (`"previews": {}` se conserva, AT-156):
   ```jsonc
   // Sin rutas en este archivo: felipecuevas.dev es un Custom Domain del panel de Cloudflare (cutover
   // del 15-11-2026, ADR-104). workers.dev apagado (ADR-101). Version URLs y URL de Worker Previews
   // apagadas (preview_urls: false) desde el cierre de E200 (ADR-124).
   // Bloque previews vacío: las previews no heredan secretos de producción (ADR-123).
   ```
   y, al final del objeto:
   ```jsonc
     "workers_dev": false,
     "preview_urls": false,
     "previews": {},
   }
   ```
3. Haz el commit, el merge a `main` y el despliegue. Espera a que el build de Workers termine.
4. **Comprobación con `curl`:** las URL de versión deben dar 404 y producción 200.
   ```bash
   for v in 53b3bdd2 820f4862 b4a0ae27; do
     printf '%s ' "$v"; curl -s -o /dev/null -w '%{http_code}\n' "https://$v-felipecuevas-dev.felipe-cuevas.workers.dev/es/"
   done
   printf 'preview '; curl -s -o /dev/null -w '%{http_code}\n' https://ajustes-visuales-felipecuevas-dev.felipe-cuevas.workers.dev/es/
   printf 'prod '; curl -s -o /dev/null -w '%{http_code}\n' https://felipecuevas.dev/es/
   ```
   Agrega también la versión que muestre el panel como activa después del despliegue.
   - **Esperado:** las versiones y la preview dan 404; producción da 200.
   - **Con esto:** AT-155 pasa a Resuelto.
   - **Si alguna da 200:** detente y avísame antes de seguir.
5. **Turnstile (AT-100):** en el panel de Cloudflare, Turnstile → el widget del sitio → Hostname Management. Quita el hostname de workers.dev y deja `felipecuevas.dev`.
   - Decide si quitas también `pages.dev`: el proyecto Pages está pausado como reversa (ADR-037), así que conviene dejarlo hasta que se retire.
   - Luego abre `https://felipecuevas.dev/es/contacto/`, da foco al primer campo y comprueba que el widget aparece sin error. No hace falta enviar.
   - **Con esto:** AT-100 pasa a Resuelto.
6. **Al terminar:** avísame para registrar AT-155 y AT-100, y para que cierres E200 (ADR-107) en `epica.md`, el README y `registro-log.md`.
